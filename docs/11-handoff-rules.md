# Handoff 文件規則

本文件說明 `handoff/` 資料夾的用途，以及日後協作產生文件的放置規則。

## 用途

`handoff/` 專門存放以下文件：

- 給前端的協作說明
- 給 PM / 設計 / 測試的臨時規格
- 當次開發或討論產生的交接文件
- 不屬於專案正式規範的工作備忘錄

這些文件的目標讀者是人，不是 AI 規則系統。

## 放置規則

從本規則建立後開始：

- 臨時協作文檔一律放在 `handoff/`
- 不放在 `docs/`
- `docs/` 只保留正式規範、架構、測試標準、API 標準與 AI 協作規則

## Git 規則

`handoff/` 已加入 `.gitignore`。

代表：

- `handoff/` 內的文件不會進入 Git 版控
- 不會被推上 GitHub
- 只會留在目前這台機器上，供專案擁有者本機查看

## 協作約定

若後續協作中需要額外產出：

- 前端串接說明
- 臨時 API 使用說明
- 交接備忘錄
- 當次改動摘要

都應優先建立在 `handoff/`。

除非使用者明確要求，否則不要把這類文件放進 `docs/`。
